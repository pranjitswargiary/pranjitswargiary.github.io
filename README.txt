PRANJIT SWARGIARY — PERSONAL WEBSITE
====================================

Files:
- index.html  Main website content
- style.css   Responsive premium dark-green / gold design
- script.js   English / Assamese language switch and mobile navigation

PREVIEW:
1. Extract the ZIP file.
2. Open index.html in a browser.

PERSONALISE BEFORE PUBLISHING:
1. Replace the "ADD YOUR PHOTO" placeholder in index.html with your own approved profile photo.
   Example:
   <img src="assets/pranjit.jpg" alt="Pranjit Swargiary">
   Add the photo file to an "assets" folder and style it in style.css.
2. Add a public email address in the Contact section if you want one displayed.
3. Check all dates, titles, awards and activity descriptions before publishing.
4. Add real event photographs to create a gallery if desired.

FREE PUBLISHING WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a public repository named: yourusername.github.io
3. Upload index.html, style.css and script.js to the repository root.
4. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
5. Your site will be published at https://yourusername.github.io/

NOTES:
- This is a static website; no paid hosting or backend is required.
- A custom domain is optional and usually costs money.
- Google Fonts are loaded from Google Fonts when internet access is available.
- Social links currently use the Instagram and YouTube handles previously supplied.
- This site is a personal portfolio, not an official college website.
- Please verify all biographical and achievement details before making the site public.
